Keep your world with you.

Pixel Quest Daybook saves your planner on this browser. It has no sign-in or cloud backup. Use an encrypted backup file to move your planner to another device.

Download and restore a backup

  1. Open Settings and enter a backup password with at least 10 characters.
  2. Choose Download encrypted backup. Keep the JSON file somewhere safe.
  3. On the other device, open Pixel Quest Daybook and go to Settings.
  4. Choose Restore backup, select the JSON file, and enter the same backup password.

Restoring replaces the planner saved in that browser. Keep a separate copy of the file before restoring. The backup password is not saved by Pixel Quest Daybook. Your diary also has its own password, which you will need to unlock diary entries on the new device.

Optional email reminders

Email reminders use a Google Apps Script project that you configure and own. Pixel Quest Daybook sends task and event titles, due times, your reminder email, and the shared secret to that script. Diary entries and notes are not included.

  1. Open Google Apps Script and create a project.
  2. Download Reminders.gs, then paste its contents into Code.gs.
  3. Open Project Settings → Script Properties. Add MOSSLIGHT_SECRET with a random secret at least 24 characters long, and MOSSLIGHT_EMAIL with your email address.
  4. Select installReminders from the function menu and click Run. Approve email and timer-trigger permissions. Run it once.
  5. Choose Deploy → New deployment → Web app. Execute as yourself and allow access to Anyone. The script checks your shared secret. Deploy and copy the URL ending in /exec.
  6. In Pixel Quest Daybook Settings, enter the URL, your email, and the same secret. Choose Save & send reminder schedule.

The script checks about every five minutes and can handle up to 200 reminders. Google mail quotas apply. You can disable the service by removing the script trigger and deployment.

Privacy and passwords

Google account sign-in and Google Drive access are not part of Pixel Quest Daybook. The backup password encrypts downloaded backups, and the diary password separately protects diary entries. Neither password can be recovered by the app.
